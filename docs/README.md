## 三句话版本

**架构**：插件（`plugin/core.mjs` 是业务逻辑唯一来源）→ 一套逻辑打成两个包装
（正式包 + 动态包）。它不碰硬件、不碰麦克风，只通过**两个文件接缝**跟外界对接：
进去的是收件箱（一行一句话），出来的是字幕总线（当前该显示的那一帧）。

**谁是插件**：**只有 `plugin/` 与 `dynamic/`**。`bridge/` `asr-eval/` `relay/` `android/`
`scripts/` `tests/` 全部跑在 harness 之外，是独立进程；它们与插件只通过那两个文件打交道
（详见 [`05-数据通路.md`](05-数据通路.md)）。

**识别评测**单独一层：代码在 `../asr-eval/`，数据在 `var/asr-eval/`（测试包 + 结果）。
它与产线的依赖是**单向**的（评测可以用产线的分段器，产线不许 import 评测）——
这条有断言在查，见 [`../asr-eval/README.md`](../asr-eval/README.md)。

**数据通路**：手机 → 转发进程 → `var/live/asr-inbox.jsonl` → 插件（判语向→翻译→排成
40×3）→ `var/live/subtitle-bus.json` → 转发进程 → 手机屏幕。
所有落盘路径只在 `../lib/paths.mjs` 定义一次。

**收音**：手机只当麦克风（16kHz、每秒一块），切句在电脑上用"自适应能量门槛 + 静音时长"
做，每句**整段**送识别，上下文续传**默认关**（实测跨场复核没通过，见 `docs/06` §3.9）。
当前缺省 `--silence-ms 800`、`--context-depth 0`、模型按设备自动选（GPU → large-v3）。
⚠️ 这两个值都是 2025 年在**真实口语**上量的：静音判定 500 → 800 在**跨 19 场录音**上
把口语错误率 27.17% 打到 20.76%；中文那句语料提示词被实测撤掉（真实口语上是负收益）。
**每个数字的依据都写在 [`06-收音策略.md`](06-收音策略.md) 里。**

**验证强度**：307 个 JS 用例 + 319 条语音相关断言 + 一次**真实 Cordis 组合**
（JS 计入的是用例数、Python 计入的是断言条数 —— 两个数字口径不同，别相加）
（真 `ToolRuntime`、真执行流水线、真 timer、真 `output.schema` 校验）。
哪些还没验证（真机麦克风、真实会议录音、端到端延迟）在各文档里都如实写着。
