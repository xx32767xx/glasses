# 26 · 可用模型清单与切换方式

> 一页纸回答两个问题：**现在能用哪些模型？怎么切到某一个？**
> 数字都标了口径与出处；没量过的就写"没量过"，不凑数。
> 实现细节见 `docs/21` §5.50（引擎抽象）/ §5.75（Parakeet、腾讯）/ §5.93（Fun-ASR）。

---

## 1. 现在实际生效的是什么（服务器 `/var/lib/leion/test`）

| 语种 | 策略名 | 引擎 | 模型 | 跑在哪 | 状态 |
|---|---|---|---|---|---|
| `en-US` | `en-parakeet` | `parakeet`（ONNX int8） | `/opt/leion/models/parakeet-tdt-0.6b-v2` | 本机 **CPU** | ✅ 实测可用（不占显存） |
| `pt-BR` | `pt-funasr` | `funasr`（DashScope 实时） | `fun-asr-realtime` | 阿里云 | ✅ 实测可用（8s 音频 2.24s 出字） |
| `zh-CN` | `zh-steady` | `whisper` | `large-v3` | 本机 **GPU**（P40 / int8_float32） | ✅ 一直在用 |

一行命令随时复查（只读，不改任何东西）：

```bash
node scripts/asr-model-switch.mjs --data-dir /var/lib/leion/test
```

它会把三门语言的「策略 → 引擎/模型」摊出来，并列出**表里所有可选的策略名**。

## 2. 全部可用模型（按引擎分组）

### 2.1 本地 whisper（faster-whisper / CTranslate2，用 GPU）

| 策略名 | 模型 | 适合 | 实测（口径） |
|---|---|---|---|
| `default` | `large-v3` | 中文主力 | 中文口语 16.9% / 葡语口语 17.4%（`asr-norm-v2` 规范化口径，holdout 504/500 条）；RTF 0.19 / 0.24（P40） |
| `en-turbo` | `large-v3-turbo` | 想快 3~4 倍、接受略降 | 本仓库**未单独测**英文 WER |
| `en-distil` | `distil-large-v3` | 纯英文蒸馏版（约 756M） | 未测英文；葡语版 `distil-whisper-large-v3-ptbr` 在 500 条巴葡上 **24.5%**（比 large-v3 差） |
| `en-tiny` | `tiny` | **只用来验证"切换真的生效"**（故意很差） | 别用于业务 |
| `en-fast` / `en-accurate` | （继承 `default`） | 只改切句窗口（快 / 准两档） | 切句参数有实测（docs/14 §6.0），模型未变 |

> ⚠️ P40 是 Pascal（算力 6.1），**没有 FP16 张量核心**：`compute_type` 必须
> `int8_float32`（或 `float32`）。表里写 `float16` 启动即失败 —— 识别侧会自动纠正并**大声说明**换过。

### 2.2 本地 Parakeet（NVIDIA Parakeet TDT 0.6B v2）

| 策略名 | 路线 | 说明 |
|---|---|---|
| `en-parakeet` | `runtime: onnx`（sherpa-onnx，**CPU**） | 英语首选。外部报告：总体 WER 2.13%、**美音 0.93%**、巴西口音英语 2.52%。本机实测 **RTF 0.10**（6.7s 音频 0.69s，8 核 Haswell），**不占显存** |
| `en-parakeet-gpu` | `runtime: nemo`（torch + NeMo） | 同模型的 GPU 路线。⚠️ 需要 `nemo_toolkit[asr]`，本机**还没装**；且 P40 上必须 `fp32` |

> 为什么英语现在用它：美音 WER 0.93% 明显好于 whisper 一档，而且走 CPU 不吃显存 ——
> 中文（whisper large-v3）继续占 GPU，两边不打架。

### 2.3 云端 DashScope（阿里 Fun-ASR，实时 WebSocket）

| 策略名 | 模型 | 实测（500 条 CORAA 巴葡，用户那批评测） |
|---|---|---|
| `pt-funasr` | `fun-asr-realtime` | **19.81%** WER / P50 938ms / P95 3202ms / **成功率 100%**（最快且最稳） |

- 需要两个环境变量：`DASHSCOPE_API_KEY`、`DASHSCOPE_WS_URL`（端点通常是**账号专属域名**，不是公开文档里那个）。
- 模型名必须用**实时（WebSocket）端点认的名字**：`fun-asr-flash-*` 那类是兼容模式的名字，能连但不能用于实时。
- 换模型前先体检：`node scripts/asr-doctor.mjs --data-dir …`（会报密钥形状对不对，不打印密钥）。

### 2.4 云端腾讯云（一句话识别）

| 策略名 | 模型（引擎编码） | 状态 |
|---|---|---|
| `en-tencent` | `16k_en` | ⛔ **还不可用**：签名与参数都已验证正确，缺的是 **CAM 授权（`QcloudASRFullAccess`）+ 服务开通**，报 `AuthFailure.UnauthorizedOperation` |

需要 `TENCENT_ASR_SECRET_ID` / `TENCENT_ASR_SECRET_KEY`（可选 `TENCENT_ASR_REGION`）。

### 2.5 评过但**没有**接进产线的

| 候选 | 巴葡 500 条结果 | 为什么没接 |
|---|---|---|
| 豆包（Volcengine 流式） | **16.02%**（最准）/ P95 5362ms | 二进制帧协议，缺官方样例代码，尚未实现引擎 |
| 讯飞 | 18.08% / P95 4058ms | 未实现引擎 |
| Qwen Audio | 24.98% / P95 3504ms | 未实现引擎（DashScope 上可用，但准确率不如 Fun-ASR） |

> 接一个新引擎 = 写一个 `AsrEngine` 子类 + 在 `build_engines()` 里登记一行（`bridge/whisper_stream.py`）。
> 引擎名不认识时**直接报错并列出已知引擎**，绝不悄悄用 whisper 顶上。

## 3. 怎么切（四种场景，按"影响范围从小到大"）

> 判定顺序（后面的覆盖前面的）：
> **命令行 → 表 `default` → `strategies[名字]` → `languages[语种]` → 房间侧车**
> 所以只改表不一定生效 —— 侧车压着它。切完用第 4 节的命令**验一遍**。

### 3.1 只改某一门语言的模型（最常见的"换个模型试试"）

```bash
# 换成表里已有的整套策略（引擎 + 模型 + 切句一起换）—— parakeet / tencent / funasr 只能这样切
node scripts/asr-model-switch.mjs --data-dir /var/lib/leion/test --lang pt-BR --strategy pt-funasr

# 只换 whisper 的尺寸名（引擎还是 whisper，切句不动）
node scripts/asr-model-switch.mjs --data-dir /var/lib/leion/test --lang zh-CN --model large-v3

# 还原成"跟策略表走"
node scripts/asr-model-switch.mjs --data-dir /var/lib/leion/test --lang pt-BR --model ""
```

- **不用重启**：识别侧按 mtime 热读表，下一段音频就生效。
- 但**进程启动时加载的那一份模型**不会自动换（那是 `--whisper-model`/表 `default` 定的）——
  换 `default` 或换 CLI 参数需要重启。

### 3.2 只在**一场会**里换（不想动全局）

```bash
node scripts/asr-model-switch.mjs --data-dir /var/lib/leion/test \
     --room room-xxxx --lang pt-BR --model large-v3
```

写的是 `asr-profiles/<房间>.json` 侧车，**只影响这一场**，下一个段生效。

⚠️ 两个注意：
1. 侧车**优先级最高**，它压着表 —— 想验证"表改了没生效"，先看 `ls /var/lib/leion/test/asr-profiles/`。
2. App 里重新开始这一场会覆盖它（手机上报名单的优先级更高）。

### 3.3 改"整张表"（给所有人的默认、或者更新策略定义）

```bash
# 预览会发生什么（默认 dry-run）
node scripts/asr-models-merge.mjs --data-dir /var/lib/leion/test

# 只加某几条策略
node scripts/asr-models-merge.mjs --data-dir /var/lib/leion/test --only pt-funasr,en-parakeet --write

# 示例表里的定义改过（例如模型名换了），要把服务器上那份也覆盖掉
node scripts/asr-models-merge.mjs --data-dir /var/lib/leion/test --only pt-funasr --replace --write
```

- 默认**只加不覆盖**（服务器上那张表可能被别人手改过）。
- `--replace` 才覆盖同名策略，并且**逐条打印覆盖了什么**；写之前自动备份成 `asr-models.json.bak-<时间戳>`。

### 3.4 临时试一个（不改任何配置）

```bash
# 命令行直接压过表（只影响这一次进程）
python bridge/whisper_stream.py --engine parakeet --model /opt/leion/models/parakeet-tdt-0.6b-v2 …

# 更推荐：单独试识别，一次一段音频，跟队列/转发/大脑全无关
node scripts/asr-try.mjs --data-dir /var/lib/leion/test                  # 队列里现有的段
node scripts/asr-try.mjs --pcm <data>/audio/<房间>/x.pcm --rate 16000 --seconds 8 --lang pt-BR
```

`asr-try` 会打印「策略 → 引擎/模型（值来自哪一层）」「电平」「分阶段耗时」，退出码 **0 出字 / 3 没出字 / 2 根本没跑到识别**。

## 4. 切完怎么确认（三条，从粗到细）

```bash
# ① 表里现在是什么（只读）
node scripts/asr-model-switch.mjs --data-dir /var/lib/leion/test

# ② 这台机器上"什么东西真的能用"（依赖/模型/密钥形状，不打印密钥）
node scripts/asr-doctor.mjs --data-dir /var/lib/leion/test

# ③ 启动日志那一行（现在会打印**解析结果**，不是只打印 model）
#    [whisper_stream] 模型表：default=whisper/large-v3；pt-BR=pt-funasr → funasr/fun-asr-realtime；…
#    每段还会打：[识别] 房间 … 策略 pt-funasr（模型 fun-asr-realtime…） → 3.2s 出词 9，耗时 2.1s
```

## 5. 常见坑（按踩过的次数排）

| 现象 | 真因 | 怎么办 |
|---|---|---|
| 改了表，行为没变 | 房间侧车压着（优先级最高） | `ls <data-dir>/asr-profiles/`；删掉或改写侧车 |
| 改了示例表，服务器没跟着变 | 合并工具默认**只加不覆盖** | 加 `--replace` |
| 换了 `default` 或 CLI 参数不生效 | 启动时加载的那份模型不会自己换 | 重启管线（`ctrl-c` 后重开） |
| 引擎名拼错 | 会**直接报错**并列已知引擎（不会静默退回 whisper） | 看报错里的清单 |
| parakeet/nemo 路线起不来 | 没装 `nemo_toolkit[asr]`/`torch` | 用 `en-parakeet`（ONNX/CPU）即可 |
| 云端连上但报参数错 | 端点不是公开域名，而是**账号专属** | 设 `DASHSCOPE_WS_URL` |
| `InvalidHeaderValue` | 密钥里混了换行（长 key 复制折行） | 重设单行密钥；`asr-doctor` 会提前告诉你 |
| 显存爆 / 突然变慢 | `--max-models` 太大或切了多个 GPU 模型 | `--max-models 2~3`；英语走 CPU 的 parakeet 更省 |
| 英语/葡语互译没选项 | 手机端的语言选项规则（5.106 已修） | 升级 APK |

## 6. 现状小结（一句话版）

- **中文**：whisper `large-v3`（GPU，int8_float32）—— 一直在用，没有更好的本地候选。
- **英文**：Parakeet TDT 0.6B v2 的 ONNX 版（**CPU**，不吃显存）；腾讯云 `16k_en` 等 CAM 授权后可比。
- **巴葡**：DashScope `fun-asr-realtime`（云端，8 秒音频 2.2 秒出字）；豆包更准（16.02% vs 19.81%）但更慢，接入需要官方样例代码。
- 底座约束：P40 无 FP16、8 核 Haswell、`/` 只剩 20G（搬模型前先看盘）。
