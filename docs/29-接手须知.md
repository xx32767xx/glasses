## 4. 下一步（按优先级，都是"没做完"的事）

1. **真机复验多语译文**（只差这一步就能收尾）：A 说英语、勾"英语+葡语"→ **只看到原文**；
   B 说中文、读中文 → 看到 `[葡] …`；同一句不会出现两张卡；不会重发上一句。
   如果不对，抓三样：`journalctl -u leion -n 60`、`[leion-pro] 译文目标：…` 那行、手机实际显示。
2. **Tencent 云识别已通（5.126，真密钥实测）**：三语都出字并有错率数字 ——
   zh `16k_zh` 3.14%（字错率，30 条 FLEURS）、pt `16k_pt` 15.82%（词错率，20 条 CORAA 口语）、
   en `16k_en` 2.70%（词错率，73 条 LibriSpeech）。**还差的不是"能不能用"，是"英语该用哪个"**：
   要跟 Parakeet **同数据同口径**在服务器上比过才能换（`var/asr-eval/packs` 还没有正式英语测试包）。
   在那之前英语保持 `en-parakeet`（见 `docs/26 §2.4`、`docs/21 §5.126`）。
3. **豆包/火山流式识别**：需要官方示例代码，建议**新开一个对话**专做。
4. **丢话报告标定**：拿一份真实整场日志算一遍，确认报告里的数与手工核对一致（① 那一项）。

## 5. 干活规矩（这几条是用户明确要求的，别自己改）

1. **一次只做一件事**，做完说清楚改了什么、验证了什么、还差什么。
2. **根因修复**：不接受"看起来好了"的补丁；日志不准说假话（宁可多打一行，也不许写一个推断当作事实）。
3. 提交前必须：`node scripts/bump-version.mjs` → `node scripts/generate.mjs` → `node tests/run-all.mjs` 全绿。
4. **本地提交，绝不 push**。
5. 安卓改完用 `node scripts/android-javac.mjs` 校验（它会自动找 `android.jar`、把 `var/cpjars/`
   下的依赖逐个列进参数文件再跑 `javac`；新增资源 id 时先用 aapt2 重新生成 `R.java`，
   脚本会检查缺不缺并告诉你命令。**不要手搓 `var/javac-check-all.txt`** —— 它是脚本产物，
   而且 `-cp "dir/*"` 的写法在 @argfile 里**不会展开**，只能逐个列）；
   UI 用语义 token（`@color`/`@dimen`），三套资源 `values` / `values-en` / `values-pt-rBR` 都要补。
6. 秘密只放 `var/secrets/`（gitignore）与 `/etc/leion/`；仓库里有测试禁止出现 `sk-ws-`、`sk-…24+`、`AKID…`。

踩过的坑（都是**不报错、只是结果不对**那一类，下次别再踩）：

| 坑 | 现象 | 已修在哪 |
|---|---|---|

| WS 用"他说什么语言"扇出 | 说话人只看得到原文 | §5.122 |
