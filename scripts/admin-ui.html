识别模型（全局策略） —

改的是服务器上的 asr-models.json：只影响之后新建的会议。 已经在开的会按它建房那一刻冻结的副本跑，不会被中途换模型（见 docs/33）。 ⚠️ 切句参数（停顿时长）不冻结：改完下一段就生效。

策略定义（模型 + 精度） 换策略 = 换模型

模型名与精度挂在策略上：上面给语言选了一个策略，它用什么模型/精度就由这里这一行决定。 想用本地下载的权重就把模型名写成绝对路径（例如 /opt/leion/models/parakeet-tdt-0.6b-v2.nemo），这样不依赖 HuggingFace 缓存目录。 ⚠️ 保存时会清掉语言行里的模型/精度覆盖（之前"换策略、模型名不变"就是它压着的）。

策略变更记录 谁改的 / 改前后

切句参数（分段） —

同传延迟 ≈ 一句话攒多久 + 静音判定 + 识别 + 翻译，而「攒多久」全由这几个数决定。 写的是服务器上的 <data-dir>/segmentation.json， 在下一段录音 / 下一场会生效（切句器是按音频流创建的，不在句子中间重建）。 ⚠️ 这里的值压过识别策略表里的同名项（现场应急优先），只有命令行仍然最强。

音频占用 —

录音是只增不减的大文件（16 kHz / 16-bit / 单声道 ≈ 115 MB/小时/路）。 这里按会议列出占用，可以单独删掉某一场的录音 —— 只腾磁盘，不动字幕与历史。 ⚠️ 删了就不能再回头核对原声（识别结果、转写全文都还在）。

会议历史数据 —

会议一多，数据库里的转写和 audio/ 下的录音会一直长。这里可以看清楚 每场会占多少，再按范围清理。⚠️ 清理是真的删数据（不是"从我的列表里藏起来"）， 进行中的会议永远不删。
