将眼镜端演示 APK 命名为 demo_glass_app.apk 放入本目录，Sample 启动时会自动拷贝并上传安装；示例包名见 SetupFlowScreen（select_scene 步骤）选择 CUSTOM_APP 时的自动预填内容。
Name the glasses-side demo APK as demo_glass_app.apk and put it in this directory; the Sample app will copy and upload/install it automatically at startup. See the auto-filled values in SetupFlowScreen (select_scene step) when choosing CUSTOM_APP for the sample package name.
