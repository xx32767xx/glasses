# 产品原型存档（老师的会议 APP 原型）

## 这是什么

`translation-app-prototype.html` —— 老师发来的**会议 APP 端到端使用原型 V0.3**（产品名占位「译连 TransLink」）。

- **单文件、离线可看**：双击这个 html 用浏览器打开即可，不需要服务器、不联网。
- 里面不只有界面：右侧三个页签是**完整规格** —— `概览`（设备组合/设计原则/参与方式）、
  `流程`（端到端 6 步）、`功能详情`（F1–F8 八个功能块）、`规则与范围`
  （发言权互斥、邀请码与管理者、后台运行、设备能力、抽屉与字号一致性、i18n、
  翻译方向、耳机播报、网络与本地模型、隐私合规、P0/P1/P2 分期）。
- 左侧是可点的手机原型（8 个页面：启动登录 / 首页 / 创建加入 / 实时房间 / 同传翻译官 /
  眼镜镜片视图 / 历史列表 / 会后纪要 / 我的），点空白区域会跳到对应功能说明。

## 为什么放进仓库

原型是**后续开发的验收依据**，放在仓库外容易丢、也无法回溯"当时老师要求的到底是什么"。
按用户要求（2026-10-23）：保留全套 APP 以备今后开发。

## 规矩

- **这是原型，不是我们的代码**：不要在这个文件上改实现、不要把业务逻辑往里加。
  它只作为规格与交互参照；实现落在 `plugin/` `relay/` `bridge/` `android/` 等处。
- **改动要留痕**：如果老师给了新版本（V0.4…），**另存新文件**（`translation-app-prototype-v0.4.html`），
  不要覆盖这一份 —— 版本之间的要求变化本身是有价值的信息。
- 文件名、字节内容与收到时一致（`Get-FileHash` 与原件相同），可作为"这份规格没被我们改过"的证据。
